1. Desafio de Espalhamento (Hashing)
- O Problema: Criar uma funcao `int espalha(char *palavra)` que mapeie 32 palavras reservadas da linguagem C para indices de um vetor de tamanho MAX, gerando o minimo possivel (idealmente zero) de colisoes.
- O que e uma colisao? Ocorre quando a funcao matematica gera o mesmo indice para duas palavras diferentes (ex: espalha("auto") resulta em 5 e espalha("break") tambem resulta em 5).
- Como testar e resolver: O programa abaixo implementa uma funcao hash famosa (djb2, criada por Dan Bernstein) que usa multiplicacao por um numero primo (33) e deslocamento de bits para espalhar bem as strings. Voce pode alterar o valor da variavel MAX no main para ver como as colisoes se comportam.

- Codigo do Desafio:
  #include <stdio.h>
  #include <string.h>

  /* Funcao de espalhamento (Algoritmo djb2 modificado para tamanho MAX) */
  int espalha(char *palavra, int max) {
      unsigned long hash = 5381;
      int c;
      while ((c = *palavra++)) {
          hash = ((hash << 5) + hash) + c; /* hash * 33 + c */
      }
      return hash % max;
  }

  int main(void) {
      char reservadas[32][20] = {
          "auto", "break", "case", "char", "const", "continue",
          "default", "do", "double", "else", "enum", "extern",
          "float", "for", "goto", "if", "int", "long",
          "register", "return", "short", "signed", "sizeof",
          "static", "struct", "switch", "typedef", "union",
          "unsigned", "void", "volatile", "while"
      };
      
      int MAX = 50; /* Altere este valor para tentar achar espalhamento perfeito (0 colisoes) */
      int tabela[1000] = {0}; /* Zera o contador de colisoes */
      int i, indice, colisoes = 0;

      printf("Testando Espalhamento com MAX = %d\n", MAX);
      for (i = 0; i < 32; i++) {
          indice = espalha(reservadas[i], MAX);
          if (tabela[indice] != 0) {
              colisoes++;
              printf("  -> Colisao detectada no indice %d (palavra: %s)\n", indice, reservadas[i]);
          }
          tabela[indice]++;
      }
      printf("Total de colisoes: %d\n", colisoes);
      return 0;
  }

2. Fundamentos: Apontadores e Registros (Structs)
- Registros (Structs): Diferente de um vetor que guarda varios elementos do MESMO tipo, a `struct` permite agrupar variaveis de TIPOS DIFERENTES sob um unico nome. E a base para criacao de "Nos" (nodes) em estruturas complexas.
- Unioes (Unions): Semelhante a struct, mas todos os seus membros compartilham o MESMO espaco de memoria. No caso do codigo abaixo (`union { float f; int i; }`), a variavel guardara um int OU um float, economizando espaco.
- Apontadores (Pointers): Sao variaveis especiais que guardam ENDERECOS DE MEMORIA em vez de valores comuns. 
  * O operador `&` obtem o endereco de uma variavel.
  * O operador `*` acessa o valor que esta guardado naquele endereco.
  * O operador `->` e um atalho. `r->tipo` e exatamente a mesma coisa que `(*r).tipo`.

3. Introducao as Listas Ligadas
- O Conceito: Vetores exigem que a memoria seja alocada de forma contigua (toda junta). Listas ligadas alocam cada elemento (No) em lugares espalhados da memoria. A ligacao entre eles e feita por um apontador: o No atual guarda o endereco do PROXIMO No.
- Vantagens: O tamanho e dinamico (cresce sob demanda usando `malloc`) e inserir/remover elementos no meio da lista e rapido O(1) se voce ja tiver o apontador para o local.
- Desvantagens: Perde-se o acesso direto O(1) aos elementos. Para achar o 5o elemento, e obrigatorio passar pelos 4 primeiros.

- Codigo de Exemplo (Prof. Leonidas): 
  Implementacao de uma lista que armazena tipos mistos (int e float).

  #include <stdio.h>
  #include <stdlib.h>

  typedef struct TipoNo {
      char tipo;
      union { float f; int i; } info; 
      struct TipoNo *prox; /* Aponta para o proximo elemento da lista */
  } TipoNo;

  void imprime_lista (TipoNo *r, int col) { 
      int aux;
      if (r != NULL) {
          /* Deslocamento horizontal para indicar profundidade (recursao) */
          for (aux = 0; aux < col; aux++) printf("   ");
          
          if (r->tipo == 'i') 
              printf("%d\n", r->info.i); 
          else                
              printf("%f\n", r->info.f);
              
          /* Chamada recursiva para imprimir o resto da lista */
          if (r->prox != NULL) imprime_lista(r->prox, col + 1);
      }
  }

  TipoNo *adiciona_no (char tipo, float valf, int vali) {
      TipoNo *aux;
      aux = malloc(sizeof(TipoNo)); /* Aloca memoria dinamicamente para o novo No */
      if (tipo == 'i') {
          aux->info.i = vali;
          aux->tipo   = 'i';
          aux->prox   = NULL;
      }
      else {
          aux->info.f = valf;
          aux->tipo   = 'f';
          aux->prox   = NULL;
      }
      return aux;
  }

  TipoNo *monta_lista (TipoNo **r) {
      TipoNo *no;
      
      /* Constroi manualmente a lista: [ i; 1 ] -> [ f; 2.0 ] -> [ f; 3.0 ] -> [ i; 4 ] */
      no = adiciona_no('i', 1, 1);
      no->prox = adiciona_no('f', 2.0, 2); 
      no->prox->prox = adiciona_no('f', 3.0, 3);
      no->prox->prox->prox = adiciona_no('i', 4, 4);
      
      printf("\n Teste impressao a partir do ultimo inserido:\n");
      imprime_lista(no->prox->prox->prox, 4);
      
      return no;
  }

  int main (void) {
      TipoNo *inicio_ll, *outro_inicio;
      printf("INICIO\n");

      outro_inicio = monta_lista(&inicio_ll);

      printf("\n Teste impressao da lista completa (a partir do primeiro):\n");
      imprime_lista(outro_inicio, 0);
      
      return 0; 
  }
