1. Tecnica: divisão-e-conquista
2. Algoritmo: Busca Binária (Busca em vetor ordenado)
3. Autores: John Mauchly (primeira menção formal)
4. Data: 1946
5. Conceitos: Vetores ordenados, recursividade ou iteração, complexidade O(log n)
6. Problema: Encontrar eficientemente um elemento em um vetor previamente ordenado descartando metade do vetor a cada passo.

7. Complexidade: O(log n)
8. Semana: Semana 03
9. Código:
#include <stdio.h>
int buscaBinaria(int arr[], int l, int r, int x) {
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (arr[m] == x) return m;
        if (arr[m] < x) l = m + 1;
        else r = m - 1;
    }
    return -1;
}
