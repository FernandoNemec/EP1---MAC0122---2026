1. Tecnica: estrutura de dados auxiliar / otimização
2. Algoritmo: Propriedade de Monte (Heap Sort)
3. Autores: J. W. J. Williams
4. Data: 1964
5. Conceitos: Ordenação, fila de prioridade, árvores, max-heap, complexidade O(n log n)
6. Problema: Ordenar um vetor interpretando-o como uma árvore binária completa, transformando-o num max-heap e iterativamente extraindo o maior elemento para a parte final do vetor.

7. Complexidade: O(n log n)
8. Semana: Semana 04
9. Código:
#include <stdio.h>
void swap(int *a, int *b) { int temp = *a; *a = *b; *b = temp; }
void heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        swap(&arr[i], &arr[largest]);
        heapify(arr, n, largest);
    }
}
void heapSort(int arr[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--) heapify(arr, n, i);
    for (int i = n - 1; i >= 0; i--) {
        swap(&arr[0], &arr[i]);
        heapify(arr, i, 0);
    }
}
