1. Tecnica: método não comparativo (frequência)
2. Algoritmo: Ordenação por frequência (LSD Radix Sort)
3. Autores: Herman Hollerith
4. Data: 1887
5. Conceitos: Ordenação, dígitos, bases, Counting Sort, complexidade O(nk)
6. Problema: Ordenar chaves inteiras agrupando os elementos pelos dígitos individuais que compartilham a mesma posição e valor significativo (do menos para o mais significativo).

7. Complexidade: O(n*k)
8. Semana: Semana 05
9. Código:
#include <stdio.h>
int getMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) if (arr[i] > max) max = arr[i];
    return max;
}
void countSort(int arr[], int n, int exp) {
    int output[n];
    int i, count[10] = {0};
    for (i = 0; i < n; i++) count[(arr[i] / exp) % 10]++;
    for (i = 1; i < 10; i++) count[i] += count[i - 1];
    for (i = n - 1; i >= 0; i--) {
        output[count[(arr[i] / exp) % 10] - 1] = arr[i];
        count[(arr[i] / exp) % 10]--;
    }
    for (i = 0; i < n; i++) arr[i] = output[i];
}
void radixSort(int arr[], int n) {
    int m = getMax(arr, n);
    for (int exp = 1; m / exp > 0; exp *= 10)
        countSort(arr, n, exp);
}
